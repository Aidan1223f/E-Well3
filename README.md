# 🧠 ewell

**ewell** is a beginner-level mental health support app that allows students to anonymously connect and chat with a counselor. The goal was to explore how technology can provide a safe and private space for students to share concerns and receive guidance.

> ⚠️ This project was an early prototype and lacks full functionality. It was created as a learning experience and proof of concept.

## 💡 Overview

- 👤 Anonymous login system for students
- 💬 Simple chat interface with a counselor
- 🛡️ Privacy-focused design approach
- 📘 Built with beginner-friendly tools and basic backend logic

## 🚧 Features (Prototype)

- Anonymous messaging system
- Basic counselor dashboard (text-only)
- Student interface for submitting messages

## 🛠 Built With

- Python (Flask)
- HTML/CSS/JavaScript (for frontend)
- SQLite or JSON (for mock data storage)
